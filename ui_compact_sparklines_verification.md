# Compact Keyword Sparklines Verification

The standalone seven-day trend card was completely removed as requested. In the "核心关键词每日排名统计表" (Core Keywords Daily Rank Statistics Table), a new "近 7 天趋势" column now sits immediately to the left of "历史最佳". Each row displays an inline SVG sparkline covering the 7-day calendar window (09/15–09/21), plotting only real snapshot data points and displaying a compact sample counter (e.g., 1/7).

This eliminates the need to select keywords one by one from a separate card and allows sales staff to scan all 6–20 core keywords' natural position movements directly inside the table.
