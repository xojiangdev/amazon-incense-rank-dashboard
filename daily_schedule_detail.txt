第一阶段——同步 Listing 与库存：依次运行 python3 /home/ubuntu/amazon-incense-rank-dashboard/scripts_spapi_collect_us_ca_fba.py、python3 /home/ubuntu/amazon-incense-rank-dashboard/scripts_spapi_collect_jp_fba.py、cd /home/ubuntu/amazon-incense-rank-dashboard && npx tsx scripts_import_verified_fba.ts。北美和日本必须分别使用隔离的 SP-API 凭证。只保留 fulfillmentChannel=FBA、inventoryStatus=Active、fulfillableQuantity>0 且属于线香/香炉/香插的商品。同步 fbaStock，并同步 FBA Inventory API 的 inboundWorkingQuantity、inboundShippedQuantity、inboundReceivingQuantity；fbaInboundTotal 必须等于三项之和。缺失于最新完整合格清单的旧商品转 Inactive；任一区域采集或审计失败时禁止做停用同步。日本站 0 条合格商品允许，但必须报告来源行数和排除原因。

第二阶段——同步 Review Rating 和评价数：运行 cd /home/ubuntu/amazon-incense-rank-dashboard && npx tsx scripts_export_product_metric_targets.ts，读取 private_spapi_import/product_metric_targets.json。对每一个 marketplace+ASIN 调用已连接的 Sorftime MCP product_detail，amz_site 按 US、CA、JP 精确传入。只接受返回 data.asin 与目标 ASIN 完全一致的结果；rating 取 data.star_rating，reviewCount 取 data.review_count，source 固定为 sorftime_product_detail。若准确返回 ASIN 但没有评分数据，可将 rating 和 reviewCount 都记为 null；任一调用失败、ASIN 不匹配、重复或遗漏时整批停止，不得部分写入。全部成功后把北京时间当前时间作为 observedAt，保存 JSON 到 /home/ubuntu/amazon-incense-rank-dashboard/private_spapi_import/product_metrics_latest.json，格式为 {observedAt,metrics:[{marketplace,asin,rating,reviewCount,source}]}，再运行 cd /home/ubuntu/amazon-incense-rank-dashboard && npx tsx scripts_import_product_metrics.ts。核对 updated 必须等于目标 Listing 总数。评分/评价数是公开商品详情指标，禁止描述为 SP-API 指标。

第三阶段——维护核心词：运行 python3 /home/ubuntu/amazon-incense-rank-dashboard/scripts_collect_sqp_keywords.py、npx tsx scripts_import_sqp_keywords.ts、npx tsx scripts_fill_keyword_minimum.ts，使每个合格 Listing 维护6–20个核心词，优先官方 SQP 出单词，其次广告出单词，最后用透明标注的自然高价值词补足，禁止把补充词标成出单词。

第四阶段——采集真实自然位、PC端广告排名与PC端SBV广告排名：读取全部排名目标；调用 Sorftime MCP product_traffic_terms 与搜索位采集工具（指定桌面端 PC 环境），对每个 ASIN 和核心词采集第1至第3页。关键词 Unicode NFKC、去首尾空格、转小写后精确匹配。自然位采用 latest_organic_position（解析为 1–60，未进前三页记 999、page=4）。同时提取该 ASIN 在 PC 端搜索结果中的常规广告曝光位（pcAdRank，SP/SB 广告，未进前三页记 999）与视频广告位（pcSbvRank，Sponsored Brands Video 广告，未进前三页记 999）。写入前必须验证 expected=actual、missing=0、extra=0、duplicates=0、invalid=0，再原子写入北京时间当日全部结果。首日 previousRank 留空/0、change=0。
